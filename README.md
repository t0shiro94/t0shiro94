## 💻 Software Development

### [Quiz Simulator](https://github.com/t0shiro94/quiz-simulator)

Desktop application designed to organize question banks and make study sessions measurable and adaptive.

**Python · PySide6 · SQLite · Pytest**

Key features include:

- training and exam modes;
- JSON and textual PDF import;
- error history and targeted review;
- adaptive question selection;
- backup and restore;
- automated tests and benchmarking;
- distributable Windows build.

[View repository →](https://github.com/t0shiro94/quiz-simulator)
